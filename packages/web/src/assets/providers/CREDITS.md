# Provider marks

`marks.ts` and `antigravity.png` hold the Claude, OpenAI, and Antigravity marks used to identify each CLI in the model picker, the page header, and the provider limits bar.

They were copied from the web client of [T3 Code](https://github.com/pingdotgg/t3code) (MIT). Claude, OpenAI, and Antigravity are trademarks of their owners. Dalang uses the marks only to show which CLI is meant and implies no endorsement.
